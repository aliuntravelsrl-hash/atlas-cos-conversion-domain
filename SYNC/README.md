# SYNC

Punto de reconciliación entre los repositorios que materializan CONVERSION.

```text
ATLAS SALES ↔ HERMES COMMERCIAL ↔ SALES MCP
                       ↕
                  CCAMEL 360
```

SYNC no significa que los componentes sean iguales. Significa que comparten el contexto necesario para que la pelota no se pierda entre mecanismos.
